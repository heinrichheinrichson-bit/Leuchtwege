# Linked Rotations trial set (1.40)

Six separate developer trial puzzles, using unchanged paired-rotation rules.
All four coupled groups remain ambiguous after repeated cell, coupling and
mandatory-network deductions. Each board needs two rounds of failed-assumption
elimination in the review model. Two search implementations confirm exactly one
solution. This is an objective selection filter, not a guarantee of perceived
human difficulty; player feedback should decide future catalogue changes.

The trial section is limited to test builds. Existing catalogue and daily puzzle
identities are unchanged. Trial sessions restore through the standard variant
storage; the last-started-per-mode resume policy remains in effect. Normal manual
completions use existing XP rules; developer assistance remains excluded.

Validation: test-linked-trials.mjs; full existing test suite; TypeScript;
production test build; Android debug build; browser menu and direct step-help.
