# Rätselprüfung – Leuchtwege

30 eindeutige Rätsel. Die bestehenden 21 Anordnungen und Speicherplätze bleiben erhalten. Die folgende Reihenfolge ist eine redaktionelle Empfehlung; die Schwierigkeit ist eine begründete Schätzung, keine Messung mit Spielern.

## Bewertungsgrundlage

- Leicht: Anschlussketten mit geringer mittlerer Ableitungstiefe.
- Mittel: längere Anschlussketten oder notwendige Verbindungen zwischen Teilnetzen.
- Schwer: die implementierten direkten Regeln reichen nicht; einzelne Möglichkeiten werden auf Widersprüche geprüft. Menschen können andere direkte Schlüsse finden.
- Die Feldgröße wird getrennt angezeigt und erhält keinen eigenen Schwierigkeitsbonus.
- Neue Rätsel sind eindeutig und keine gedrehten/gespiegelten Duplikate. Über 90 % identische Bauteiltypen an entsprechenden Positionen werden für neue Rätsel vermieden. Dies ist eine einfache Ähnlichkeitsprüfung, kein Beweis gleicher Spielerfahrung.
- Manuelle Zuordnungen können mit Begründung in difficulty-overrides.json hinterlegt werden; aktuell gibt es keine vorgetäuschten Spielerbewertungen.
